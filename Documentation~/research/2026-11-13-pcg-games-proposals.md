# Proposals from 20 procedural games (2026-11-13)

Research material, not authority. Source: the wrapped «Mundos desde una semilla» (https://claude.ai/artifact/HLxMj8NRPTE7omTNjjswuA), with sourced game notes in `banco-ideas-juego/juegos-procedurales/investigacion/`. Cross-checked against `CURRENT_STATE.md`, `PCG_Roadmap.md` and `technique_integration_matrix.md` on 2026-11-13 (survey by a read-only agent). All items are proposals; anything touching `Runtime/` moves goldens and goes through governance.

**Conflicts to decide (Claudio):** the matrix (§9) excludes midpoint displacement and the 5D biome query; items 4–5 brush against them. **Doc error found:** the matrix marks Poisson disk as DONE in runtime, but it only exists in the web (Islands Lab).

1. **Continents by accretion and by plates** (Civilization 1; Seven Cities of Gold; Dwarf Fortress). For the NoiseLab v6 continents step: random-walk chunks that raise land where they overlap, with a land-quota parameter (Civ: `(landMass+2)×320` tiles of 80×50); and colliding plates that raise ranges (Phase K). Measure against noise in NoiseLab first. No Runtime change.
2. **One seed per layer and per coordinate** (Dwarf Fortress separate seeds; Akalabeth per-dungeon seed; Diablo per-level seeds; No Man's Sky position chain). Today: one `Unity.Mathematics.Random` per run with stage salts (`MapContext2D.cs`). Proposal: stage seed = `SmallXXHash(seed, stageId)`; local cell seed = `SmallXXHash(seed, x, y, level)` (Akalabeth's `10x+1000y+31.4·level` collides; use a real hash). Enables the world→cell zoom and «same world but drier». Contract decision; moves goldens.
3. **Bad-world rubric = rejection with minima** (DF rejection params; Diablo minimum floor 533/693/761; Civ river rollback; Star Trek regeneration). Unblocks the paused Phase P: a list of measurable per-map checks, first as a report, later as rejection.
4. **Erosion with temporary rivers and an «age»** (DF; Civ age = 800×(1+age) passes). Before hydrology: temporary rivers from mountain bases wear the relief, then Priority-Flood → D8 runs on the carved channels. Single visible parameter: age. The matrix already recommends hydraulic erosion before L.
5. **Biome by nearest box in climate space** (Minecraft 1.18 multi-noise). C+E·PV exists only in NoiseLab; the pipeline still uses Whittaker 2D. Intermediate step: nearest box in 4D (temperature, humidity, continentalness, erosion), boxes as data. Decide whether 4D falls under the §9 exclusion.
6. **Flatten peaks and pits for terraces** (The Sentinel). For discrete-height tile maps (PL-5 terraces, local map): quantize, then two row/column passes that lower a vertex above both strip neighbours and raise one below both. Small deterministic operator.
7. **Local cells: path first, templates after** (Spelunky 4×4 walk; Diablo; Rogue spanning tree plus `rnd(5)` extra corridors). For the mundo-islas cell zoom and one village per cell. Missing today: guaranteed-path templates and the room graph (Delaunay + MST + cycles; backlog #5).
8. **Names with per-people phonotactics** (Elite digram table; DF name seed). Regions use name tables (`RegionNameTableAsset`). Minimal layer before the Band Manager text-generator module: syllable pairs per culture chosen by region-seed bits, plus the Taller's banned-word filter.
9. **History as artefact + ancient society** (Caves of Qud event → rationalised cause → state; RimWorld ancient roads before factions). For mundo-islas, not the package. Grammars authored with LLM help in the studio (LLM as co-designer only).
10. **Narrator = tension controller** (RimWorld storytellers: cycles, minimum spacing, points by wealth/population, adaptation). For the mundo-islas narrator, «rules first, LLM as voice». Prototype: the page's storyteller demo.
11. **Classic generators as Islands Lab chapters** (Pitfall reversible LFSR, Elite bit-derived data, Sentinel mini layered pipeline, Rogue spanning tree): demos already written in the page. Plus fix the Poisson entry in the matrix.
